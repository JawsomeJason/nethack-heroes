# Architecture decision records

An ADR records one decision, why it was made and what it costs.
ADRs are never edited to change a decision. A new ADR supersedes the old one.
Every later session and contributor starts from the Accepted ADRs.

## How to add one

1. Take the next number and write `NNNN-short-title.md` in this folder.
2. Copy the section layout of an existing ADR: Status, Context, Decision, Consequences, Evidence.
3. Set the status to Proposed, Accepted or Superseded, with the date.
4. Keep it between 15 and 35 lines.
5. Add a row to the index below.
