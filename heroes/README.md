# Heroes

This fork turns NetHack 5.0 into an original superhero roguelike.
The game is a theme pack in Lua and text data over an almost untouched C engine.
A downstream theme pack can sit on the same seam and rename or narrow the game.

## Status

The design is agreed. The first playable slice is in progress.
The wave-1 heroes, five origins and the first mission are playable.
